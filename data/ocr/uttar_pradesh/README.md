# Uttar Pradesh draft page readings

These ten `.proposed.txt` files were prepared by AI from rendered Hindi PDF pages on 27 September 2026. No Tesseract/OCR dependency is added to the application. They are selected substantive English readings, not official translations. The existing loader's proposed-text path validates each file against its original PDF/page and recorded hashes.

`review.json` records derivation, scope and false acceptance flags. The 2024 old-provision column and administrative distribution lists are omitted explicitly. The operator checklist preserves its mandatory and indicative columns. Citation source labels disclose the English-reading status and link to the original Hindi page. Team review and actual reviewer/date remain pending; a hash match only proves unchanged bytes.
