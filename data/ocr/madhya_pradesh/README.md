# Madhya Pradesh text proposals

The original operational guide already has an OCR layer. Raw `.txt` files preserve that extraction; proposed files contain selected AI corrections or explicit table/flow readings compared with rendered physical pages. Page 1 is a selected unofficial English translation of the Hindi issuing order; the circulation list is omitted. Sixteen proposals are mapped by source/page and hashes in `review.json`.

The shared notebook loader selects only these mapped pages. Other guide pages retain their unverified PDF OCR layer and carry a derivation label. No OCR installation is required to run the project. The complete original PDF remains the citation target. All reviewer/date fields are null and all acceptance flags are false pending the team's review. The RWA flow/annexure wording differences are recorded in the source review.
